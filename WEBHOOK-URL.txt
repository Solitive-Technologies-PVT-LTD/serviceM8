📋 Steps to Configure in ServiceM8:
───────────────────────────────────────────────────────────────
1. Log into ServiceM8 Dashboard
2. Go to: Settings → Integrations → Webhooks
3. Click "Add Webhook" or "New Webhook"
4. Paste the Webhook URL above
5. Select events to subscribe to:
   ✓ Job Created
   ✓ Job Updated  
   ✓ Job Completed
   ✓ Invoice Created
   ✓ Invoice Updated
6. Save and copy the Webhook Secret (if provided)
7. Add secret to .env file: SERVICEM8_WEBHOOK_SECRET=your-secret
